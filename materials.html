Software & Open Data

Open-source code repositories, simulation suites, and curated empirical datasets

In accordance with open science practices, code and curated datasets for my research projects are archived in public repositories with permanent digital object identifiers (DOIs).

Repositories & Packages

Bangladesh-Seasonal-Reclassification (UGC Grant Pipeline)
Complete analysis pipeline for 30 years of daily and monthly meteorological records from 33 Bangladesh Meteorological Department (BMD) stations (1985–2014, 10,865 station-months). Contains quality control routines, circular contiguous partition searches, Ward clustering, and 1,000 bootstrap resamplings over years and stations.
Zenodo DOI: 10.5281/zenodo.23324622 GitHub
massive-variance-stability-test (MVT Package)
Python and R implementation of the Massive Variance Stability Test (MVT). Includes segmented variance calculation, asymptotic chi-square p-values, 10,000-replication Monte Carlo simulation engines, and empirical tests on financial volatility series.
Zenodo DOI: 10.5281/zenodo.22861296 GitHub
ERA5-Land Monsoon Climatological Pipeline (AR-FMC Framework)
Processing scripts for ECMWF ERA5-Land reanalysis over Bangladesh (1950–2025). Handles NetCDF4 grid files, clips 1,214 terrestrial cells, extracts 122-day cumulative monsoon profiles (1 June to 30 September), and produces 92,264 normalized functional curves for autoregressive model-based clustering.
Departmental Academic Records Management System
Full-stack database and workflow management application built with Python (Flask) and PostgreSQL. Developed for academic record management and verification.
